git init -b main
Explanation: Initializes a new local Git repository and names the default branch main.

git config user.name "Assignment Student"
Explanation: Sets the author name that will appear in commit history.

git config user.email "student@example.com"
Explanation: Sets the email address used for commit metadata.

git add index.html about.html
Explanation: Stages the project files so they are ready to be committed.

git commit -m "Initial project setup"
Explanation: Saves the initial project state as the first version-controlled snapshot.

git add index.html
Explanation: Stages the updated homepage file for the next commit.

git commit -m "Update homepage content"
Explanation: Records the second change to the project history.

git checkout -b feature
Explanation: Creates and switches to the feature branch for independent work.

git add about.html
Explanation: Stages the modified feature branch content before committing it.

git commit -m "Add feature branch content"
Explanation: Saves the feature branch changes as a separate commit.

git checkout main
Explanation: Switches the working directory back to the main branch.

git merge feature --no-ff -m "Merge feature branch into main"
Explanation: Integrates the feature branch work into main while preserving the merge commit history.

git log --oneline --decorate --graph --all
Explanation: Displays the full commit history and branch activity for review.

cat > .gitignore
Explanation: Creates the ignore file that lists files and folders Git should skip.

*.log
Explanation: Ignores log files generated by the application.

temp/
Explanation: Ignores the temporary folder so generated files are not tracked.

git add .gitignore
Explanation: Stages the .gitignore file before committing it.

git commit -m "Add gitignore"
Explanation: Saves the ignore rules in the project history.

release-notes.txt
Explanation: Creates a file that represents an additional development change for the undo exercise.

git add release-notes.txt
Explanation: Stages the new release note file.

git commit -m "Add release notes"
Explanation: Creates an additional commit before undoing it.

git reset --soft HEAD~1
Explanation: Removes the last commit while keeping the changes staged, demonstrating an undo operation.

git status --short --ignored
Explanation: Shows the repository state after the reset and confirms that ignored files are not tracked.

git remote add origin https://github.com/yourusername/sdp-assignment.git
Explanation: Connects the local repository to the GitHub remote location.

git push -u origin main
Explanation: Uploads the repository to GitHub, after creating a public repository and authenticating.
