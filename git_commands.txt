Explanation: Creates the about page for the website and stores the initial content in version control.

git add index.html about.html
Explanation: Stages the new project files so they are included in the next commit.

git commit -m "Initial project setup"
Explanation: Records the baseline repository state as the first commit.

git add index.html
Explanation: Stages the modified homepage content before creating the second commit.

git commit -m "Update homepage content"
Explanation: Saves the second version of the project while preserving the commit history trail.

git checkout -b feature
Explanation: Creates a feature branch and switches the working tree to it for isolated development.

cat > about.html <<'EOF'
...feature branch HTML update...
EOF
Explanation: Adds a branch-specific change to demonstrate parallel development work.

git add about.html
Explanation: Stages the feature-specific modification prior to commit.

git commit -m "Add feature branch content"
Explanation: Creates a dedicated commit on the feature branch to record the branch work.

git checkout main
Explanation: Switches the repository back to main so the feature branch can be integrated.

git merge feature --no-ff -m "Merge feature branch into main"
Explanation: Merges the feature branch into main while preserving a merge commit in the history.

git log --oneline --decorate --graph --all
Explanation: Displays the complete commit graph and branch activity for verification.

cat > .gitignore <<'EOF'
*.log
temp/
EOF
Explanation: Creates a .gitignore file that ignores all log files and the temp directory.

git add .gitignore
Explanation: Stages the ignore rules before saving them in the repository.

git commit -m "Add gitignore"
Explanation: Records the ignore configuration in the project history.

printf 'sample log content\n' > debug.log
Explanation: Creates a simulated log file to demonstrate that Git will ignore it.

mkdir -p temp
printf 'temporary content\n' > temp/temp-file.txt
Explanation: Creates a temporary folder and sample content to verify the ignore rule.

git status --short --ignored
Explanation: Shows ignored files and folders, confirming that .log and temp/ are being excluded.

printf 'Release version 1.0 notes for the project.\n' > release-notes.txt
Explanation: Creates an additional file to be used in the revert/undo exercise.

git add release-notes.txt
Explanation: Stages the new release-notes file before committing it.

git commit -m "Add release notes"
Explanation: Produces an additional commit that will later be undone to demonstrate recovery.

git reset --soft HEAD~1
Explanation: Undoes the latest commit while keeping the file changes staged, showing a Git undo operation without losing work.

git status --short
Explanation: Displays the repository state after the reset, proving the reverted commit is still in the index.

git remote add origin https://github.com/Sharan-code-sys/Git_Workflow_Test_Case_Assignment.git
Explanation: Connects the local repository to the public GitHub remote used for final delivery.

git push -u origin main
Explanation: Pushes the full branch history and repository content to the public GitHub remote.
